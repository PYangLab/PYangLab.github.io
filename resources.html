Software ecosystem

Software and resources

Our software ecosystem supports the lab's research programme in cell identity, interpretable AI, single-cell and spatial omics, organoid systems, and disease-state modelling.

The resources below are organised to match the five research directions on the Research page. General-purpose tools and legacy projects are retained after the tabs so the full software record remains visible.

Research direction 1

Cell identity and cell-fate decisions

Tools for defining cell identity, improving annotation, integrating single-cell references, modelling multimodal identity signals and prioritising candidate regulators or compounds for cell-state conversion.

Cell identity genes

Cepo

Identifies cell-identity genes using differential stability in single-cell RNA-seq data.

Docs Bioconductor Paper

Annotation correction

scReClassify

Post hoc cell-type reclassification method for correcting potentially mislabelled single-cell annotations.

Repo Bioconductor Paper

Multiscale annotation

scClassify

Performs multiscale cell-type classification using single or multiple references and supports sample-size estimation.

Docs Bioconductor Paper

Single-cell integration

scMerge

Integrates and normalises single-cell RNA-seq data using stably expressed genes and pseudo-replicates.

Docs Bioconductor Paper

Multimodal identity modelling

Matilda

Multi-task learning framework for multimodal single-cell omics, including simulation, dimension reduction, classification and feature selection.

Repo Docs PyPI Paper

Cell-state conversion

Refate

Prioritises candidate genes, networks and compounds for directed cellular conversion from starting to target cell states.

Repo Tutorial Shiny Preprint

Research direction 2

Interpretable AI for single-cell systems biology

Tools and frameworks for learning from high-dimensional single-cell and multimodal data while exposing the features, programs and cell states that support each prediction.

Interpretable deep generative learning

Hydra

Deep generative ensemble learning framework for unimodal and multimodal single-cell omics, with interpretable feature attribution and cell-type annotation.

Repo Tutorial PyPI Paper

Multi-task learning

Matilda

Jointly learns several multimodal single-cell tasks, including simulation, classification, feature selection and representation learning.

Repo Docs PyPI Paper

Feature selection benchmark

scDeepFeatures

Evaluation resource for deep learning-based feature selection in single-cell RNA-seq analysis.

Repo Paper

Positive-unlabelled learning

AdaSampling

Adaptive sampling for positive-unlabelled and label-noise learning in bioinformatics applications.

Repo CRAN Paper

Research direction 3

Single-cell, spatial and multimodal omics tools

Tools and benchmarks for reproducible data integration, annotation, multimodal analysis, spatial transcriptomics, phosphoproteomics and related machine-learning foundations.

Multimodal benchmarking

scMultiBench

Multitask benchmark for single-cell multimodal omics integration methods across vertical, diagonal, mosaic and cross-modality settings.

Repo Shiny Paper Highlight

Spatial benchmarking

SVGbench

Benchmark resource for evaluating spatially variable gene detection methods in spatial transcriptomics data.

Repo Paper

CITE-seq analysis

CiteFuse

Supports preprocessing, integration, clustering, differential analysis and visualisation for CITE-seq data.

Docs Bioconductor Paper

Phosphoproteomics

PhosR

Processes phosphoproteomic data and supports kinase, pathway, signalome and phosphorylation-site analyses.

Docs Bioconductor Paper Protocol

Knowledge-guided clustering

CLUEY

Knowledge-guided framework for cell-type detection and clustering of unimodal and multimodal single-cell omics data.

Repo Paper PMC

Stable genes and phosphosites

Pathway and kinase analysis

directPA and KinasePA

Pathway and kinase perturbation analysis for transcriptomic, proteomic and phosphoproteomic datasets.

Kinase-substrate prediction

Research direction 5

Disease-state modelling and therapeutic prioritisation

Tools for identifying disease-associated cell states, interpreting altered molecular features and prioritising candidate targets or compounds.

Disease-associated cells

Hydra

Interpretable deep generative ensemble learning framework for identifying cell-type-specific features and preserving disease-relevant signatures.

Repo Tutorial PyPI Paper

Directional molecular change

SwitchClass

Label-switch classification framework for distinguishing attenuated and escalated molecular features across perturbation, recovery and disease trajectories.

Repo Preprint

Sample-level modelling

scFeatures

Generates sample-level multi-view representations from single-cell and spatial data for disease-outcome modelling.

Docs Bioconductor Paper

Candidate intervention prioritisation

Refate

Links regulatory-network modelling to candidate compound prioritisation for directed cell-state conversion and reprogramming hypotheses.

Repo Tutorial Shiny Preprint

Signalling and phosphorylation

PhosR

Supports phosphoproteomic processing and kinase/signalling analyses relevant to disease-state interpretation.

Docs Bioconductor Paper
